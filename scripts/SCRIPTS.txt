XFDemo operational scripts
===========================

Runtime
  scripts/backend/start_backend.sh
  scripts/backend/stop_backend.sh
  scripts/backend/check_backend.sh
  scripts/auth/start_auth_db.sh
  scripts/auth/stop_auth_db.sh

Deployment
  scripts/package_stack.sh
    Builds both images into output/deploy/images/.

  scripts/upload_deploy.sh
    Uploads image archives from output/deploy/images/ and configuration
    from deploy/. It does not start containers.

  scripts/deploy_remote.sh <user@host> [remote_dir]
    Uploads the same bundle, loads both images, and starts Docker Compose.

Configuration remains in deploy/. Generated image archives remain in output/.
